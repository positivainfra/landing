FAQ

Before you request your first raw footage.

Do my clients have to learn how to use it?

No. They only open a link: to see what you share or to upload what you ask for. Files is your tool, not theirs.

How much can someone upload to me?

Whatever fits in your storage. File requests have no size or file-count limit of their own.

Does the file request link expire?

Not on its own. It stays open until you close it once you have the material, or until an expiry date if you set one.

Can I password-protect a file request?

No. File requests don’t have a password: anyone with the link can upload. If the link reaches the wrong person, you close the request or regenerate its link. The links you use to share files and folders can have a password.

Which plan includes it?

Folders, multi-file uploads and file requests are on the Studio plan (1 TB). On the Free and Author plans, Files holds individual files that you share one by one. Client galleries and proofing are on every plan.

Can several people use the same link?

Yes. They all upload to the same folder, each into their own subfolder, and you see every file with the uploader’s name.
